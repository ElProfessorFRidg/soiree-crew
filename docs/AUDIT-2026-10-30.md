# Feature audit, 30 October 2026

Three reviewers checked every ID marked "build" in FEATURES.md against the code. 292 rows: 141 OK, 149 partial, 1 missing (O-38), 1 not working on iOS (AC-02). This file is the work list; FEATURES.md now marks these IDs "partial" until each gap below is closed.

Cross-cutting: there are no push notifications (O-38). The server only sends hints over the live socket, so anything meant to reach a locked phone does not. iOS push needs an APNs key from a paid Apple developer account, which is not confirmed yet; the server side is to be built ready to plug in, with an in-app notification inbox and local notifications meanwhile.
