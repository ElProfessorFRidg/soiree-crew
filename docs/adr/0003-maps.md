# ADR 0003: Maps

Status: accepted, 2026-10-27.

## Context

TER-01 needs a fast map of the crew's venues on iOS, Android and the web preview, in the night theme of DESIGN.md. The app is built in CI without platform keys (ADR 0001).

## Decision

- A small raster tile map in TypeScript (`apps/mobile/src/map/TileMap.tsx`): web-mercator maths, pan and pinch through Gesture Handler on the UI thread, tiles recomputed only when a gesture ends.
- Night theme: Esri World Dark Gray Canvas, which answers without a key. Day theme: OpenStreetMap standard tiles. The attribution of the source in use is always on screen.
- This is a stopgap for a crew-sized app. Before any public release, move to OpenFreeMap vector tiles (free, no key, no request limit) rendered with MapLibre Native, styled with our tokens.

## Rejected

- CARTO basemaps: now answer with an "API key required" tile.
- react-native-maps: Google Maps needs a key on Android, and Apple Maps cannot be styled to the slate palette.
- MapLibre now: a native module to validate against React Native 0.88 and the New Architecture first; planned, not urgent for personal use.

## Consequences

- No vector styling, labels come from the tile provider.
- OpenStreetMap's tile policy forbids heavy use: fine for a crew, not for a public app.
